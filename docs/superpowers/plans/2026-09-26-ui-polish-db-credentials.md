# UI polish + database credentials Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the owner's eleven UI requests: per-database credentials kept in Windows Credential Manager with a Test connection, one bottom-right action-dock standard, a smooth large-group unfold, images in comments, and six small copy/layout fixes.

**Architecture:** Rust gains a `db::credentials` module (secret store trait + Credential Manager impl + resolution by database id) and commands that replace the connection-string plumbing; the webview keeps only the selected id and non-secret fields. **Tech Stack:** Tauri 2, Rust (`windows-sys` 0.61 for Credential Manager), React 19 + TS, react-query, vitest/jsdom, tauri-specta generated bindings.

**Spec:** `docs/superpowers/specs/2026-09-26-ui-polish-db-credentials-design.md`

- [ ] **Step 4: Implement `db/credentials.rs`.** Key pieces (keep module docs in the house style - explain why, not what):

```rust
//! Where each database's login lives. Rust owns it: the webview gets a
//! public view (who signs in, whether a password is saved) and never the
//! password or the full connection string. See the design at
//! docs/superpowers/specs/2026-09-26-ui-polish-db-credentials-design.md.

use crate::db::sqlcmd::parse_connection;
use crate::db_defaults::DB_PRESETS;

pub const OWN_ID: &str = "own";
const OWN_LABEL: &str = "Your own database";
const SEMICOLON: &str = "The login can't contain a semicolon.";

fn target(id: &str) -> String { format!("tcm-v2/db/{id}") }

fn shipped(id: &str) -> Option<&'static crate::db_defaults::DbPreset> {
    DB_PRESETS.iter().find(|p| p.id == id)
}

fn known(id: &str) -> Result<(), String> {
    if id == OWN_ID || shipped(id).is_some() { Ok(()) } else { Err("That database is not one the app knows.".into()) }
}

/// "host,port" -> ("host", Some(port)); a bad port stays part of the host.
fn split_server(server: &str) -> (String, Option<u16>) {
    match server.rsplit_once(',') {
        Some((h, p)) => match p.trim().parse() { Ok(n) => (h.trim().into(), Some(n)), Err(_) => (server.trim().into(), None) },
        None => (server.trim().into(), None),
    }
}

fn build(server: &str, port: Option<u16>, database: &str, user: &str, password: &str, trust: bool) -> Result<String, String> {
    if [server, database, user, password].iter().any(|v| v.contains(';')) { return Err(SEMICOLON.into()); }
    let mut s = format!("Server={}{}", server.trim(), port.map(|p| format!(",{p}")).unwrap_or_default());
    s.push_str(&format!(";Database={};User Id={};Password={}", database.trim(), user.trim(), password));
    if trust { s.push_str(";TrustServerCertificate=True"); }
    Ok(s)
}
```

`resolve`: `known(id)?; if let Some(v) = store.get(&target(id))? { return Ok(Some(v)) }; Ok(shipped(id).map(|p| p.connection_string.to_string()))`.
`apply_form`: current = `resolve(...)?` parsed with `parse_connection` when present. Shipped id: server/port/database/trust come from the SHIPPED string (form's ignored); user from form; password = form's if `Some(non-empty)` else current's (override, else shipped). Own: everything from the form; password = form's if non-empty else current own's; no password at all -> `Err("Enter a password.")`; blank server or database -> `Err("Enter the server and database.")`. Then `build(...)`.
`save`: `let conn = apply_form(..)?; store.put(&target(id), &conn)?; Ok(view(store, id)?)`.
`view(store,id) -> Result<DbDatabase,String>`: from `resolve`; parse (a string that fails `parse_connection` shows empty fields); `has_password = !password.is_empty()`; `customised = store.get(&target(id))?.is_some()`; label = preset label or `OWN_LABEL`.
`databases`: map every id through `view`, skipping (and `applog::warn`-ing) one that errors, so a broken entry never hides the rest.
`reset`: own -> error sentence above; else `store.remove(&target(id))?` then `view`.
`forget_all`: remove `OWN_ID` and every preset id.
`find_shipped`: normalise = split `;`, trim, drop empties, for each `k=v` -> `k.to_lowercase().replace(' ', "") + "=" + v.trim()`, sort, join `;`; compare with each preset's normalised string.

`CredentialManager` (Windows) with `windows_sys::Win32::Security::Credentials::{CredReadW, CredWriteW, CredDeleteW, CredFree, CREDENTIALW, CRED_TYPE_GENERIC, CRED_PERSIST_LOCAL_MACHINE}` and `windows_sys::Win32::Foundation::{GetLastError, ERROR_NOT_FOUND}`: targets as UTF-16 NUL-terminated `Vec<u16>`; `put` writes `CredentialBlob` = UTF-8 bytes, `UserName` = `"tcm-v2"` wide string; `get` returns `Ok(None)` on `ERROR_NOT_FOUND`, copies the blob to a `String` (lossy UTF-8) and always `CredFree`s; `remove` treats `ERROR_NOT_FOUND` as success. Errors: `put` -> `"Could not save the login in Windows Credential Manager."`, `get` -> `"Could not read the saved login."`, `remove` -> `"Could not remove the saved login."`, each after `crate::applog::warn` with the Win32 error code (never the value). Match the exact windows-sys 0.61 type aliases the compiler asks for (e.g. `BOOL` is `i32`, pointers are raw). Put the `unsafe` blocks in small functions with a `// SAFETY:` line each. On non-Windows, a `CredentialManager` impl whose three methods return `Err("Windows Credential Manager is not available.".into())`.

`DbCredentialsForm`'s `Debug`: hand-written, prints `password: "(hidden)"` like `sqlcmd::Connection`.

In `db_defaults.rs` add `pub id: &'static str` to `DbPreset` and fill the three ids. In `db/mod.rs` add `pub mod credentials;`.

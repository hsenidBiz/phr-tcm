# Auto Run: Unattended Replay, Review and Send to Azure DevOps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tester picks scripted cases and presses one button; the app runs every case from a fresh browser with no click per step (in the background by default), keeps evidence for every step, proposes a verdict per case, and waits for the tester to confirm or change each verdict; a reviewed run can then be sent to Azure DevOps as one test run by pressing a button.

**Architecture:** A pure replay engine (`autorun/replay.rs`) drives `runner::run_step` over a `Browsers` source that hands it one fresh driver per case, so the whole loop is testable against the fakes; the Tauri command supplies real browsers (headless unless "Watch the browser" is on), emits a progress event per step, honours a cancel flag between steps, and saves the run to disk after every case. Records grow optional fields (`proposed`, `reason`, `duration_ms`, a per-step screenshot, `mode`, `published`) so every older run file still loads and the human's `verdict` stays the human's. Publishing lives in its own module (`autorun/publish.rs`) and reuses the manual Test Runner's write path (create run, record result with per-step marks and attachments, complete run): POST and PATCH only, never creating a plan or suite, only when the person presses Send.

**Tech Stack:** Rust (Tauri 2, tauri-specta commands and events, tokio, serde_json, wiremock in tests), Chrome DevTools Protocol, React 19 + TypeScript, TanStack Query, vitest.

**Owner decisions (2026-09-22):** the app proposes a verdict and the person confirms it (nothing counts until confirmed); sending to Azure DevOps is a button per reviewed run, never automatic; the browser runs in the background by default with a "Watch the browser" switch per run.

**Background:** `docs/research/2026-09-21-phr-playwright-automation-analysis.md` section 11 item 4; the closing sections of `docs/superpowers/plans/2026-09-21-autorun-driver-locators-assertions.md` (parked item 1) and `docs/superpowers/plans/2026-09-21-autorun-accounts-signin-sessions.md`.

## Global Constraints

- Every Rust test is an integration test under `src-tauri/tests/`; never a `#[cfg(test)]` module inside `src/`. Shared fakes are in `src-tauri/tests/common/mod.rs` (`ScriptedDriver`, `FakePage`, `StatefulApp`).
- One build or test command at a time on this shared machine. Rust commands run from `src-tauri/` with `CARGO_TARGET_DIR=target/gate`. The frontend suite runs as `npx vitest run --exclude "**/.claude/**"`.
- `src/bindings.ts` is generated by `cargo test --test bindings`; never hand-edit it. A line-ending-only diff on it is reverted with `git checkout -- src/bindings.ts`.
- No new crates.
- **`verdict` is the human's word.** The machine writes `proposed` and `reason`, never `verdict`. A case counts only once a person has confirmed or changed its verdict in the review screen. Nothing unconfirmed is ever sent to Azure DevOps.
- **Azure DevOps is touched only by `autorun/publish.rs` and its command, only when the person presses Send, only with GET, POST and PATCH.** There are no DELETE calls anywhere in this app and none may be added. Publishing never creates a test plan or a suite: it uses the read-only suite lookup, and says what to do when there is none. Driving the browser (`commands/autorun.rs`, `autorun/runner.rs`, `autorun/replay.rs`) still never calls Azure DevOps.
- A transport error's `to_string()` never reaches the user: Azure DevOps failures surface as `AdoError` the way every other command's do (`ado/transport.rs` `network_error`).
- Every case starts from a fresh browser and profile. A case's sign-in goes through `signin::sign_in`; the password rule from the accounts plan holds (never in a log, a detail, a run file, a progress event or anything sent to Azure DevOps).
- Every run and script file saved before this plan still loads; a supervised run is written exactly as before (new fields absent, not null).
- A failure that is the browser's fault says so in words containing "browser"; a failure that is the page's says what was seen.
- Auto Run stays a development-build tab (`AUTO_RUN_ENABLED`), and its assistant tools stay development-only behind the AI Bridge switch. No new assistant tool in this plan.
- No em dashes in text a user or an assistant reads. Colours via tokens; button icons from `src/lib/actionIcons.ts` as `<IconX aria-hidden />`; `src/ui-consistency.test.ts` must not be weakened; dropdowns are the themed `Select`; dialogs are the shared `Modal`.
- Commits use a Bash heredoc `git commit -q -F - <<'EOF' ... EOF`; the trailer names the model that wrote the commit.

**Out of scope, on purpose:** scheduled or recurring runs; running while the app is closed; parallel cases (one browser at a time, so one account at a time holds by construction); retrying a failed case automatically; a bounded healer (phase 5); reading a field's value back after typing (masks and formatters make it a judgement call; stays parked); publishing as an "automated" run type (the planned-points manual run is what the Test Runner already writes and what the board reads).

    pub run_id: String,
    pub index: u32,        // 0-based position in the selection
    pub total: u32,
    pub case_id: i32,
    pub title: String,
    /// "opening", "signing_in", "step" or "done"

**The rules (each has a test):**
1. Every case gets its own browser from `browsers.open()` and gives it back with `close`, also when the case fails. A browser that will not open gives a case proposed `Blocked` with reason `the browser did not open: {why}` and the run goes on to the next case.
2. A script that names an account is signed in first. The sign-in's outcomes are recorded as step `SIGN_IN_STEP` (0). A failed sign-in: no script step runs (each is recorded with one outcome per action reading `not run: the sign-in failed`), proposed `Blocked`, reason is the sign-in's detail.
3. Steps run in order through `run_step`. After a step in which any action failed, the remaining STEPS are not run: each is recorded with one outcome per action reading `not run: an earlier step of this case failed`. (Inside a step the existing rule stands: actions after an ordinary failure still run.)
4. After every executed step a picture is taken with `runner::picture` and its name stored in `StepRecord.screenshot`, unless one of the step's outcomes was a harness failure (never ask a browser that has stopped answering for a picture).
5. `propose`: a harness failure anywhere, a browser that did not open, or a failed sign-in gives `Blocked`; otherwise any failed action gives `Failed` with reason `step {n}: {detail of the first failed action}`; otherwise, if the script contains at least one check (`Action::is_check`), `Passed` with reason `every action of {k} steps passed`; otherwise nothing is proposed (`""`) with reason `this script checks nothing, so there is nothing to propose`. A case stopped by the person proposes nothing, reason `stopped before it finished`.
6. `verdict` is always `""` and `note` is always `""` in what the engine writes. `duration_ms` is the wall time of the case, `account` is the script's account key.
7. The run is saved with `store::save_run` after EVERY case, so a crash or a stop loses nothing. A save that fails does not stop the run; the first such error is what `run_selection` returns at the end.
8. `cancel` is looked at before each case and before each step. Cases not started when it is set are left out of the run entirely. The case in progress records its remaining steps as `not run: the run was stopped`.
9. A selection entry whose script is missing is recorded with no steps, nothing proposed, reason `this case has no script on this machine`.
10. Progress: `opening` before `open()`, `signing_in` before a sign-in, `step` before each executed step, `done` after the case with its `proposed`.

//! Running whole cases with nobody pressing a button per step.
//!
//! Pure: it is handed its browsers, its clock is `Instant`, and the only
//! thing it writes is the run file. It never calls Azure DevOps, and it
//! never fills in a verdict: what it thinks is `proposed`, and a person
//! confirms or changes it afterwards.

use super::runner::{self, as_action_outcome};
use super::signin;
use super::{store, CaseRecord, CaseScript, LocalRun, StepRecord, StepScript};
use crate::browser::actions::ActionOutcome;
use crate::browser::cdp::Driver;
use crate::browser::timing::Timing;
use crate::events::ReplayProgress;
use std::path::Path;
use std::sync::atomic::{AtomicBool, Ordering};
use std::time::Instant;

pub const SIGN_IN_STEP: i32 = 0;
const AFTER_FAILED_STEP: &str = "not run: an earlier step of this case failed";
const AFTER_FAILED_SIGN_IN: &str = "not run: the sign-in failed";
const AFTER_STOP: &str = "not run: the run was stopped";

pub trait Browsers {
    type D: Driver;
    fn open(&mut self) -> impl std::future::Future<Output = Result<Self::D, String>>;
    fn close(&mut self, d: Self::D) -> impl std::future::Future<Output = ()>;
}

pub struct Proposal {
    pub verdict: &'static str,
    pub reason: String,
}

fn not_run(step: &StepScript, why: &str) -> StepRecord {
    StepRecord {
        step_number: step.step_number,
        outcomes: step.actions.iter().map(|_| ActionOutcome::failed(why)).collect(),
        screenshot: None,
    }
}

fn was_run(o: &ActionOutcome) -> bool {
    !o.detail.starts_with("not run:")
}

/// `signed_in`: None when the script names no account, Some(ok) otherwise.
pub fn propose(script: &CaseScript, steps: &[StepRecord], signed_in: Option<bool>, stopped: bool) -> Proposal {
    let ran = || steps.iter().flat_map(|s| s.outcomes.iter().map(move |o| (s.step_number, o))).filter(|(_, o)| was_run(o));
    if let Some((n, o)) = ran().find(|(_, o)| !o.ok && o.harness) {
        let at = if n == SIGN_IN_STEP { "while signing in".to_string() } else { format!("at step {n}") };
        return Proposal { verdict: "Blocked", reason: format!("the browser stopped answering {at}: {}", o.detail) };
    }
    if signed_in == Some(false) {
        let why = steps.iter().find(|s| s.step_number == SIGN_IN_STEP).and_then(|s| s.outcomes.last()).map(|o| o.detail.clone()).unwrap_or_default();
        return Proposal { verdict: "Blocked", reason: why };
    }
    if let Some((n, o)) = ran().find(|(_, o)| !o.ok) {
        return Proposal { verdict: "Failed", reason: format!("step {n}: {}", o.detail) };
    }
    if stopped {
        return Proposal { verdict: "", reason: "stopped before it finished".into() };
    }
    if !script.steps.iter().flat_map(|s| &s.actions).any(|a| a.is_check()) {
        return Proposal { verdict: "", reason: "this script checks nothing, so there is nothing to propose".into() };
    }
    Proposal { verdict: "Passed", reason: format!("every action of {} steps passed", script.steps.len()) }
}

pub async fn run_case<D: Driver>(
    d: &mut D,
    root: &Path,
    organization: &str,
    project: &str,
    script: &CaseScript,
    timing: &Timing,
    cancel: &AtomicBool,
    on_step: &mut (dyn FnMut(i32) + Send),
) -> CaseRecord {
    let began = Instant::now();
    let mut steps: Vec<StepRecord> = Vec::with_capacity(script.steps.len() + 1);
    let mut signed_in = None;
    let mut account = None;

    if let Some(key) = &script.account {
        on_step(SIGN_IN_STEP);
        let out = match signin::prepare(root, organization, project, key) {
            Err(why) => vec![ActionOutcome::failed(why)],
            Ok((recipe, who)) => {
                let signed = signin::sign_in(d, root, &recipe, &who, timing).await;
                let mut all = signed.steps.clone();
                all.push(as_action_outcome(&signed));
                all
            }
        };
        let ok = out.last().is_some_and(|o| o.ok);
        signed_in = Some(ok);
        steps.push(StepRecord { step_number: SIGN_IN_STEP, outcomes: out, screenshot: None });
    }

    // Why the rest of the case is not being run, once something decided that.
    let mut skip: Option<&'static str> = (signed_in == Some(false)).then_some(AFTER_FAILED_SIGN_IN);
    let mut stopped = false;
    for step in &script.steps {
        if skip.is_none() && cancel.load(Ordering::SeqCst) {
            skip = Some(AFTER_STOP);
            stopped = true;
        }
        if let Some(why) = skip {
            steps.push(not_run(step, why));
            continue;
        }
        on_step(step.step_number);
        let outcomes = match runner::run_step(d, root, organization, project, step, timing, &mut account).await {
            Ok(o) => o,
            Err(why) => step.actions.iter().map(|_| ActionOutcome::failed(why.clone())).collect(),
        };
        let harness = outcomes.iter().any(|o| !o.ok && o.harness);
        let screenshot = if harness { None } else { runner::picture(d, root).await };
        if outcomes.iter().any(|o| !o.ok) {
            skip = Some(AFTER_FAILED_STEP);
        }
        steps.push(StepRecord { step_number: step.step_number, outcomes, screenshot });
    }

    let p = propose(script, &steps, signed_in, stopped);
    CaseRecord {
        case_id: script.case_id,
        title: script.title.clone(),
        verdict: String::new(),
        note: String::new(),
        steps,
        proposed: p.verdict.to_string(),
        reason: p.reason,
        duration_ms: i32::try_from(began.elapsed().as_millis()).ok(),
        account: script.account.clone(),
    }
}

fn unrun(case_id: i32, title: &str, proposed: &str, reason: String) -> CaseRecord {
    CaseRecord {
        case_id,
        title: title.to_string(),
        verdict: String::new(),
        note: String::new(),
        steps: vec![],
        proposed: proposed.to_string(),
        reason,
        duration_ms: None,
        account: None,
    }
}

pub async fn run_selection<B: Browsers>(
    browsers: &mut B,
    root: &Path,
    organization: &str,
    project: &str,
    run: &mut LocalRun,
    cases: &[(i32, String)],
    timing: &Timing,
    cancel: &AtomicBool,
    progress: &mut (dyn FnMut(ReplayProgress) + Send),
) -> Result<(), String> {
    let total = cases.len() as u32;
    let mut save_error: Option<String> = None;
    for (index, (case_id, title)) in cases.iter().enumerate() {
        if cancel.load(Ordering::SeqCst) {
            break;
        }
        let mut tell = |phase: &str, step_number: i32, steps: u32, proposed: &str| ReplayProgress {
            run_id: run.id.clone(),
            index: index as u32,
            total,
            case_id: *case_id,
            title: title.clone(),
            phase: phase.to_string(),
            step_number,
            steps,
            proposed: proposed.to_string(),
        };
        let record = match store::load_script(root, *case_id) {
            Err(why) => unrun(*case_id, title, "", format!("the script could not be read: {why}")),
            Ok(None) => unrun(*case_id, title, "", "this case has no script on this machine".into()),
            Ok(Some(script)) => {
                let count = script.steps.len() as u32;
                progress(tell("opening", 0, count, ""));
                match browsers.open().await {
                    Err(why) => unrun(*case_id, title, "Blocked", format!("the browser did not open: {why}")),
                    Ok(mut d) => {
                        let mut on_step = |n: i32| {
                            let phase = if n == SIGN_IN_STEP { "signing_in" } else { "step" };
                            progress(tell(phase, n, count, ""));
                        };
                        let rec = run_case(&mut d, root, organization, project, &script, timing, cancel, &mut on_step).await;
                        browsers.close(d).await;
                        rec
                    }
                }
            }
        };
        let proposed = record.proposed.clone();
        let steps = record.steps.len() as u32;
        run.cases.push(record);
        if let Err(e) = store::save_run(root, run) {
            save_error.get_or_insert(e);
        }
        progress(tell("done", 0, steps, &proposed));
    }
    save_error.map_or(Ok(()), Err)
}

//! The unattended run's IPC shell: real browsers for the replay engine,
//! progress as events, one run at a time, and a way to stop.

use crate::autorun::replay::{self, Browsers};
use crate::autorun::{store, LocalRun};
use crate::browser::cdp::Cdp;
use crate::browser::launch::{background_args, launch_with, Browser, LaunchedBrowser};

use crate::events::ReplayProgress;
use std::sync::atomic::{AtomicBool, Ordering};
use std::time::Duration;
use tauri_specta::Event;

static RUNNING: AtomicBool = AtomicBool::new(false);
static CANCEL: AtomicBool = AtomicBool::new(false);

pub struct OneAtATime(());

impl OneAtATime {
    pub fn claim() -> Option<OneAtATime> {
        RUNNING
            .compare_exchange(false, true, Ordering::SeqCst, Ordering::SeqCst)
            .ok()
            .map(|_| OneAtATime(()))
    }
}

impl Drop for OneAtATime {
    fn drop(&mut self) {
        RUNNING.store(false, Ordering::SeqCst);
    }
}

pub fn replay_timing(watch: bool) -> Timing {
    let t = Timing::default();
    if watch { t } else { Timing { highlight_ms: 0, ..t } }
}

struct RealBrowsers {
    which: Browser,
    watch: bool,
    current: Option<LaunchedBrowser>,
}

impl Browsers for RealBrowsers {
    type D = Cdp;

    async fn open(&mut self) -> Result<Cdp, String> {
        let extra = background_args();
        let browser = launch_with(self.which, if self.watch { &[] } else { &extra })?;
        // The debugging port answers when the browser is ready, which varies
        // with what else the machine is doing. Asking until it does beats a
        // fixed sleep that is either slow or flaky.
        let mut last = String::new();
        for _ in 0..60 {
            tokio::time::sleep(Duration::from_millis(250)).await;
            match Cdp::connect(browser.port).await {
                Ok(cdp) => {
                    self.current = Some(browser);
                    return Ok(cdp);
                }
                Err(e) => last = e,
            }
        }
        super::autorun::close_browser(browser);
        Err(format!("it started but never answered: {last}"))
    }

    async fn close(&mut self, d: Cdp) {
        drop(d);
        if let Some(b) = self.current.take() {
            super::autorun::close_browser(b);
        }
    }
}

2. Only cases whose `verdict` is `Passed`, `Failed` or `Blocked` are sent. A case with `verdict == ""` is `skipped` with `no verdict was confirmed`, whatever was proposed. The proposal is never sent as an outcome.
3. Points come from `get_test_points(org, project, plan, suite, &confirmed_case_ids)`. A confirmed case with no point in the suite is `skipped` with `it is not in this PBI's test suite`. 4. One run is created with `create_test_run(plan, run_name, &point_ids)`; every point of a case (one per configuration) gets that case's outcome.
5. Each result is recorded through `record_point_outcome` with: `outcome` = the verdict; `comment` = `comment_for`; `duration_ms`; `step_ids` + `step_outcomes` = `step_marks`; `attachments` = `pictures_for` loaded with `store::load_shot` and base64-encoded, named `case-{id}-step-{n}.jpg` (a second picture of the same step gets `-2`); no bug ids.
6. **Once the run exists, nothing that goes wrong is an `Err`.** A result that will not record, a run that will not complete, a picture that is no longer on disk: each becomes a sentence in `problems`, and the run is STILL marked as sent, because a run that exists in Azure DevOps and is not remembered here would be sent twice. `Err` is only for failures before `create_test_run` succeeded.
7. After the results: `complete_test_run`. Then `published = Some(PublishedRun { run_id, web_url, at })` is written with `store::save_run` (not the guarded save: this is the one writer allowed to set it). If that save fails, `problems` gains `this machine could not record that the run was sent - do not send it again: {web_url}`.
8. `comment_for`: the person's note first (if any), a blank line, then `Auto Run` plus ` as {account}` when there is one, `: `, and the reason (or `no reason recorded`). Never longer than 1000 characters (`update_run_results` caps it; do not rely on that for the note: if the whole is too long, the reason is what gets cut, never the person's note).
9. `step_marks`: one entry per Azure DevOps step id, in order; entry `i` looks at the run's step with `step_number == i + 1`: `None` when there is no such step or none of its outcomes was run (`not run:` prefix), `Some("Failed")` when any run outcome is not ok, otherwise `Some("Passed")`. 10. `pictures_for`: every failed action's `screenshot`, then the step-end picture of the last executed step; duplicates by name removed; first `MAX_PICTURES_PER_CASE` kept.

```rust
pub async fn publish_run(
    client: &AdoClient,
    root: &Path,
    organization: &str,
    project: &str,
    suite: &EnsuredSuite,
    run_name: &str,
    run_id: &str,
    cases: &[PublishCase],
) -> Result<PublishResult, AdoError> {
    let refused = |why: String| Ok(PublishResult::Refused { why });
    let Ok(Some(mut run)) = store::load_run(root, run_id) else {
        return refused("this run is no longer on this machine".into());
    };
    if let Some(p) = &run.published {
        return refused(format!("this run was already sent to Azure DevOps: {}", p.web_url));
    }
    let confirmed: Vec<&CaseRecord> =
        run.cases.iter().filter(|c| matches!(c.verdict.as_str(), "Passed" | "Failed" | "Blocked")).collect();
    let mut skipped: Vec<SkippedCase> = run
        .cases
        .iter()
        .filter(|c| !confirmed.iter().any(|k| k.case_id == c.case_id))
        .map(|c| SkippedCase { case_id: c.case_id, why: "no verdict was confirmed".into() })
        .collect();
    if confirmed.is_empty() {
        return refused("confirm at least one verdict before sending".into());
    }

    let ids: Vec<i32> = confirmed.iter().map(|c| c.case_id).collect();
    let points = client.get_test_points(organization, project, suite.plan_id, suite.suite_id, &ids).await?;
    let points_of = |case_id: i32| -> Vec<i32> {
        points.iter().filter(|p| p.test_case_id == Some(case_id)).map(|p| p.point_id).collect()
    };
    for c in &confirmed {
        if points_of(c.case_id).is_empty() {
            skipped.push(SkippedCase { case_id: c.case_id, why: "it is not in this PBI's test suite".into() });
        }
    }
    let sendable: Vec<&CaseRecord> = confirmed.iter().copied().filter(|c| !points_of(c.case_id).is_empty()).collect();
    if sendable.is_empty() {
        return refused("none of these cases is in the PBI's test suite in Azure DevOps".into());
    }
    let point_ids: Vec<i32> = sendable.iter().flat_map(|c| points_of(c.case_id)).collect();

    // From here on a run exists in Azure DevOps. Nothing below may return Err.
    let created = client.create_test_run(organization, project, suite.plan_id, run_name, &point_ids).await?;
    let mut problems: Vec<String> = Vec::new();
    let mut sent: Vec<i32> = Vec::new();
    let results = match client.get_run_results(organization, project, created.run_id).await {
        Ok(r) => r,
        Err(e) => {
            crate::applog::warn(format!("auto-run publish: run {} results could not be read: {e}", created.run_id));
            problems.push("the new run's result rows could not be read, so no outcome was recorded in it".into());
            vec![]
        }
    };
    use base64::Engine;
    for case in &sendable {
        let id = case.case_id;
        let step_ids = cases.iter().find(|c| c.case_id == id).map(|c| c.step_ids.clone()).unwrap_or_default();
        let marks = step_marks(case, &step_ids);

        let mut attachments = Vec::new();
        let mut per_step: std::collections::HashMap<i32, usize> = std::collections::HashMap::new();
        for (step, name) in pictures_for(case) {
            match store::load_shot(root, &name) {
                Ok(bytes) => {
                    let n = per_step.entry(step).or_insert(0);
                    *n += 1;
                    let file_name = if *n == 1 {
                        format!("case-{id}-step-{step}.jpg")
                    } else {
                        format!("case-{id}-step-{step}-{n}.jpg")
                    };
                    attachments.push(RunAttachment { file_name, b64: base64::engine::general_purpose::STANDARD.encode(bytes) });
                }
                Err(_) => problems.push(format!("case {id}: the picture of step {step} is no longer on this machine")),
            }
        }

        let mut every_point_recorded = true;
        for point_id in points_of(id) {
            let Some(result_id) = results.iter().find(|r| r.point_id == Some(point_id)).map(|r| r.result_id) else {
                every_point_recorded = false;
                problems.push(format!("case {id}: Azure DevOps made no result row for test point {point_id}"));
                continue;
            };
            let outcome = PointOutcome {
                point_id,
                outcome: case.verdict.clone(),
                comment: Some(comment_for(case)),
                duration_ms: case.duration_ms,
                step_ids: Some(step_ids.clone()),
                step_outcomes: Some(marks.clone()),
                attachments: Some(attachments.clone()),
                bug_ids: None,
            };
            match record_point_outcome(client, organization, project, created.run_id, result_id, &outcome).await {
                Ok(extras) => problems.extend(extras.into_iter().map(|x| format!("case {id}: {x} was not saved"))),
                Err(e) => {
                    crate::applog::warn(format!("auto-run publish: run {} case {id} was not recorded: {e}", created.run_id));
                    every_point_recorded = false;
                    problems.push(format!("case {id}: its outcome was not recorded"));
                }
            }
        }
        if every_point_recorded {
            sent.push(id);
        }
    }

    if let Err(e) = client.complete_test_run(organization, project, created.run_id).await {
        crate::applog::warn(format!("auto-run publish: run {} could not be completed: {e}", created.run_id));
        problems.push("the run was left In Progress in Azure DevOps - complete it there".into());
    }

    run.published = Some(PublishedRun {
        run_id: created.run_id,
        web_url: created.web_url.clone(),
        at: super::sessions::now_ms().to_string(),
    });
    if let Err(e) = store::save_run(root, &run) {
        crate::applog::warn(format!("auto-run publish: run {} could not be marked as sent: {e}", created.run_id));
        problems.push(format!(
            "this machine could not record that the run was sent - do not send it again: {}",
            created.web_url
        ));
    }

    skipped.sort_by_key(|s| s.case_id);
    Ok(PublishResult::Sent(PublishReport { run_id: created.run_id, web_url: created.web_url, sent, skipped, problems }))
}

use v2_lib::autorun::replay::{run_selection, Browsers};
use v2_lib::browser::launch::background_args;

/// One real background browser per `open`, with the same patience as `open()`
/// above, counting how many were started.
struct LiveBrowsers {
    started: usize,
    current: Option<LaunchedBrowser>,
}

impl Browsers for LiveBrowsers {
    type D = Cdp;
    async fn open(&mut self) -> Result<Cdp, String> {
        let extra = background_args();
        let browser = launch_with(Browser::Edge, &extra)?;
        self.started += 1;
        let mut last = String::new();
        for _ in 0..60 {
            tokio::time::sleep(Duration::from_millis(250)).await;
            match Cdp::connect(browser.port).await {
                Ok(c) => {
                    self.current = Some(browser);
                    return Ok(c);
                }
                Err(e) => last = e,
            }
        }
        Err(last)
    }
    async fn close(&mut self, d: Cdp) {
        drop(d);
        if let Some(mut b) = self.current.take() {
            let _ = b.child.kill();
            let _ = b.child.wait();
            for _ in 0..20 {
                if std::fs::remove_dir_all(&b.profile_dir).is_ok() || !b.profile_dir.exists() {
                    break;
                }
                std::thread::sleep(Duration::from_millis(100));
            }
        }
    }
}
```

6. Send to Azure DevOps: the confirmation names the PBI and the counts. After sending, open the run in Azure DevOps: one run, the confirmed cases only, each outcome as you set it, your note leading the comment, the failed step marked failed, the pictures attached. The unset case has no result.
7. The test points on the board (Run Tests, and Azure DevOps' own Test Plans) show the new outcomes.
8. Send is no longer offered for that run; the review is read-only and says when it was sent.
9. A PBI that has no suite yet: Send refuses and says to open Run Tests once. Nothing was created in Azure DevOps.
10. Unplug the network and press Send: the failure reads like the app's other Azure DevOps failures (no URL in it), and Send can be pressed again afterwards.
11. A supervised run ("Run 1 selected") works exactly as before and its past-run entry has no Review button.
12. Kill Edge from Task Manager in the middle of an unattended case: that case is proposed Blocked and says the browser stopped answering; the next case still runs.

## What execution changed from this plan

Read from `progress.md`, the nine task reports (fix rounds included) and the diffs the reports point at. Every code claim below was checked against the source as it stands after Task 9's own changes.

**Task 1 (leftovers: origin matching, session restore, hung-browser wording).** Two pre-existing tests in `browser_expect.rs` and `browser_input.rs` encoded the exact bug the task fixed (a call that burns the whole wait budget with no completed look was asserted as page wording, not harness); both were renamed and their assertions flipped to expect a harness outcome, which the task brief itself called the point of the fix, not scope creep. `FakePage` gained a real `answer(method, params)` method and moved its call counters onto the struct as `Cell<usize>` so a test could mix scripted cutoffs with real answers, something the brief's own sketch assumed existed. The "let the whole first look through" test needed an exact call-count gate (5 calls, not 1), because a look is more than one protocol round trip; the brief had flagged this as a risk and the implementer worked out the real number by reading `resolve`/`page::call_elements`/`look`. One deferred minor remains: `is_bare_origin` no longer accepts two or more trailing slashes, fail closed and untested.

**Task 2 (`LocalRun`/`CaseRecord`, `store::save_run_guarded`, `auto_run_save_run`/`auto_run_load_run`).** Implemented essentially as given. A fix round closed one important finding: `save_run_guarded` originally used `if let Ok(Some(existing))` to decide whether to refuse an overwrite, which silently treated an unreadable (corrupt) existing run file the same as "nothing there yet" and let an unpublished copy overwrite the record of a published run. It now matches explicitly on `load_run`'s result and refuses with a stated reason when the existing file cannot be read, and also checks `safe_run_id` itself rather than trusting its caller.

**Task 3 (`autorun::replay` engine, `propose`, `run_case`, `run_selection`, `ReplayProgress`).** The brief's own closure-based sketch for building `ReplayProgress` values (`tell`) borrowed `run.id` for the loop while `run.cases.push` needed `run` mutably later in the same loop; it was rewritten as a plain function taking every field by value, with identical emitted values, to remove the borrow conflict. A fix round closed two findings. Important: `run_selection` sent the script's own step count on `opening`/`signing_in`/`step` but the RECORDED step count (0 for a case whose browser never opened) on `done`, which the brief's own sketch had gotten wrong; `count` is now computed once and used for every phase of a case including `done`. This is the exact field Task 9's tests check for case 1's phase list. Minor: rule 7's failure half (a save that fails does not stop the run, and is reported at the end) was untested; `a_save_that_fails_does_not_stop_the_run_and_is_reported_at_the_end` was added to `tests/autorun_replay.rs`, writing a plain file where the runs directory would go so every `store::save_run` call fails, and asserting `run_selection` still returns `Err` (the first save error, surfaced at the end) while both cases still land in `run.cases` and both `"done"` progress events still arrive.

**Task 4 (`commands/autorun_replay.rs`, `RealBrowsers`, `OneAtATime`).** Implemented as given; the one thing the brief flagged as a possible friction point, converting `Cdp::connect`'s error type, was unnecessary because `Cdp::connect` already returns `Result<Cdp<WsTransport>, String>`. **Task 5 (`autorun::publish`, `auto_run_publish`, attachments and pictures).** A fix round closed one important finding: the original `auto_run_publish` checked "already sent" and "nothing confirmed" only after fetching a token and looking up the suite, so a run that could never be sent still cost Azure DevOps requests. Five minor findings were also closed in the same round: a log line right after a successful `create_test_run`, the "sending run X for PBI #Y to plan #Z" line changed from `warn` to `applog::info` with a `logged` flag so it fires once per call rather than once per retry pass through the cached-suite loop, `skipped` computed from each case's own verdict instead of an O(n·m) lookup, `pictures_for` excluding "not run:" outcomes the same way `mark_for_step` already did, and a wording fix ("was not saved" to "did not save").
